## About Me

I’m a Computer Science student at Virtual University of Pakistan, based in Lahore, Pakistan. I’m learning and building practical web applications with a strong focus on frontend engineering and full-stack development.

My journey started with learning HTML, CSS, JavaScript, and modern frontend concepts, and it has grown into working with React, Next.js, TypeScript, Tailwind CSS, Node.js, Express.js, MongoDB, and Supabase. I enjoy building user-friendly interfaces and connecting them to real application functionality.

I’m particularly interested in:
- building responsive, accessible web experiences
- learning full-stack architecture
- working with real projects and team-based development
- exploring modern AI-assisted workflows without losing technical understanding

I’m currently looking for opportunities where I can continue learning, contribute to real projects, and grow as a developer.
